# 🌐 多自主智能体系统（Multi-Agent Systems）· 从入门到精通

> 📘 28章 实战体系 · 交互式 HTML 课程

> **English TL;DR:** An all-Chinese 28-chapter course on **multi-agent systems (MAS)** — from single-agent cognition (perceive-plan-act / ReAct) and MAS fundamentals (cooperation/competition hybrid, game theory, Nash) and multi-agent RL (CTDE, VDN/QMIX, MADDPG/MASAC/MAPPO), then the LLM-agent rise and the frameworks that define 2026 orchestration: LangGraph (state graphs, checkpoints), CrewAI (role-based teams), AutoGen / Microsoft Agent Framework (GroupChat, Magentic-One), MetaGPT (software-company-as-society), plus the protocols MCP (tool-layer USB) and A2A (agent internet). Production & frontier: security (prompt injection, agent "immune system" ANIS), observability/Token economics, decentralized topologies (AgentNet DAG), metacognition, self-evolving agents (LIFE), end-to-end RL (MetaAgent-X), embodied collective intelligence, and the agent-internet five-layer protocol stack — ending with two LangGraph/CrewAI hands-ons and a self-evolving R&D-assistant MAS capstone.

## 📖 课程简介

本课程系统讲授**多智能体系统（MAS）**：从单体智能体的认知架构（感知-规划-行动 / ReAct）出发，进入 MAS 的基础理论（协同/竞争、博弈论、多智能体强化学习 CTDE/QMIX/MAPPO 与通信协调）；随后重点覆盖 **LLM 多智能体编排**——LangGraph 图状态机、CrewAI 角色化团队、AutoGen/MAF 的 GroupChat 与 MetaGPT 的「软件公司即智能体社会」，并贯穿 MCP（工具层）与 A2A（智能体间）两大协议。生产与前沿侧涵盖安全攻防与免疫系统、可观测性/Token 经济、去中心化拓扑、元认知、自进化、端到端 RL 训练、具身集体智能与 Agent 互联网，最后以 LangGraph / CrewAI 两个实战与自进化研发助手 MAS 综合项目收束。
